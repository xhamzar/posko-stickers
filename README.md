# POSKO Stickers

CDN stiker resmi POSKO (Pusat Obrolan & Sharing Komunitas Online).
File disajikan lewat jsDelivr:

- Manifest: https://cdn.jsdelivr.net/gh/xhamzar/posko-stickers@main/manifest.json
- Stiker: https://cdn.jsdelivr.net/gh/xhamzar/posko-stickers@main/packs/<pack>/<nama>.webp

## Pack

- **maskot** — Maskot POSKO (Kucing Songong), 12 ekspresi, pixel art 384×384 WebP transparan dengan border putih.

Stiker digambar prosedural (PIL) — bebas dipakai di dalam POSKO.
